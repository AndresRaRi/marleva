# Lenguaje y presentación de M1

15-10-2026. MAR-CHAT-006. Dirección visual aprobada expresamente por el usuario: verde, fondo cálido, tipografía del sistema y navegación Cuenta/Avisos/Ayuda. Referencia revisada: [propuesta](../revision/M1/PROPUESTA_VISUAL_M1.html). La aprobación de esta dirección no acredita pruebas ni aceptación del módulo.

Usar palabras comunes y acciones concretas: Recibir código, Verificar código, Consultar estado, Cerrar esta sesión. Explicar qué ocurrió y la siguiente acción disponible. No presentar un error de consulta como una lista vacía. Mostrar espera, error, dato confirmado y operación pendiente como estados distintos.

Al vencer la sesión, pedir acceso por correo y conservar únicamente el destino interno ligado a la misma cuenta. No mostrar códigos, correos nuevos, claves de autenticador o capacidades de la sesión anterior. Un código incorrecto conserva el campo para corregirlo; nunca anunciar un cambio completado sin confirmación del servidor.

La recuperación del segundo factor explica la revisión por otra persona autorizada y el requisito de acceso reciente. No prometer recuperación del buzón ni convertir pertenencia vecinal en transferencia de cuenta. La demostración local identifica los datos ficticios y la ausencia de pagos reales.

Controles con nombre accesible, estado deshabilitado/ocupado y superficie mínima de 48 puntos; campos etiquetados, texto escalable y errores anunciados. Las pruebas automáticas complementan las comprobaciones de teclado, lector y plataformas; no representan por sí solas conformidad WCAG.
